
A simple romantic interactive webpage built with HTML, CSS, and JavaScript.  
The page reveals a sweet love message with smooth animations when the user clicks on the intro text.

**Features**

- Beautiful green gradient background
- Smooth fade-in and hover animations
- Interactive click-to-reveal message
- Romantic programmer-themed love note
- Beginner-friendly project structure

**Technologies Used**
- HTML5
- CSS3
- JavaScript

**Project Structure**

To-You-Babe/

│
├── index.html
├── style.css
└── script.js


**How It Works**
The page first displays "Lovey-Dovey Knock"
When clicked:
The intro text disappears
A hidden romantic message appears
Animation effects are triggered


**Animations Included**
Fade In
Slide Up
Bounce Glow
Hover Scale Effect
